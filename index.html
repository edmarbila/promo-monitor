Como conseguir API ID e API Hash

  1. Acesse my.telegram.org.
  2. Entre com seu número.
  3. Abra API development tools.
  4. Crie uma aplicação e copie api_id e api_hash.
  5. Informe os dados abaixo e confirme o código recebido no Telegram.

Os dados são enviados ao backend e armazenados criptografados. Eles não são gravados em um `.env` do navegador.

Como o projeto funciona

O painel salva configurações no Supabase. A Control API faz a autenticação no Telegram e guarda os segredos criptografados. O worker fica online independentemente do navegador, monitora mensagens, mantém apenas 24 horas de histórico e alimenta a central de cupons.

Cada usuário é isolado por RLS e vê somente seus próprios dados.
