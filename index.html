Como conseguir API ID e API Hash

  1. Acesse my.telegram.org.
  2. Entre com seu número.
  3. Abra API development tools.
  4. Crie uma aplicação e copie api_id e api_hash.
  5. Informe os dados abaixo e confirme o código recebido no Telegram.

Os dados são enviados ao backend e armazenados criptografados. Eles não são gravados em um `.env` do navegador.

Como receber no celular

  1. Instale o aplicativo ntfy no celular.
  2. No ntfy, use o servidor padrão ntfy.sh. Não é necessário criar outro servidor.
  3. Escolha Inscrever-se em tópico.
  4. Use exatamente o mesmo nome de tópico mostrado pelo Promo Monitor.
  5. Depois de se inscrever nesse tópico no ntfy, clique em Enviar teste.

Você pode usar um tópico automático ou personalizar o nome. O sistema sempre acrescenta uma sequência aleatória de segurança.

Nome do tópico

Obrigatório usar pelo menos uma letra e um número. Espaços serão convertidos em hífens.

Prévia do tópico final —

No aplicativo ntfy, mantenha o servidor padrão ntfy.sh e inscreva-se em um tópico com exatamente este mesmo nome. Se gerar ou salvar outro nome aqui, atualize também a inscrição no ntfy. O botão Enviar teste usa somente o tópico já salvo e nunca cria outro.

Como o projeto funciona

O painel salva configurações no Supabase. A Control API faz a autenticação no Telegram e guarda os segredos criptografados. O worker fica online independentemente do navegador, monitora mensagens, mantém apenas 24 horas de histórico e alimenta a central de cupons.

Cada usuário é isolado por RLS e vê somente seus próprios dados.
